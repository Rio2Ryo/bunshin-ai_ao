# 価値観波形（G+/G-）の特許ドキュメント調査結果

## 調査目的
MBTIやビッグファイブとは別の「価値観」に基づく波形評価システムについて、特許ドキュメントでどのように定義されているかを調査する。

---

## 特許における価値観波形の定義

### 1. 価値観波形とは（図7より）

**構造:**
- **縦軸**: 累積値（上が「徳」、下が「地雷」）
- **横軸**: 各模倣人格（C1, C2, C3, C4, C5, ..., Cn-1）
- **G+(Un)**: 徳の累積波形（ポジティブな評価）
- **G-(Un)**: 地雷の累積波形（ネガティブな評価）

### 2. 波形生成プロセス（図6より）

**E01〜E05のフロー:**
1. ユーザUnがチャット等の言動を実行
2. ユーザUnの言動情報を**全模倣人格（C1〜Cn-1）に監視させる**
3. 言動情報から想起された**多数の言動項目**について模倣人格に**評価・累積させる**
4. 全言動項目の評価が完了
5. 模倣人格ごとの徳および地雷の累積結果を示す価値観波形G+(Un),G-(Un)を算出

### 3. 評価の仕組み

**重要ポイント:**
- 各模倣人格は**異なる価値観・判断基準**を持つ
- 同じ言動でも模倣人格によって評価が異なる
- 評価は「徳」「地雷」「問題なし」の3段階
- **多角的な評価**により高精度な人格把握が可能

---

## 価値観の閾値（判断基準）- 9つの軸

特許では以下の9つの判断基準が定義されている：

1. **善悪** - 行為の道徳的な正しさ
2. **好き嫌い** - 個人的な好み
3. **損得** - 経済的・実利的な判断
4. **利害** - 利益と害の関係
5. **苦楽** - 苦痛と快楽の判断
6. **難易** - 難しさと易しさの判断
7. **可否** - 可能性の判断
8. **快不快** - 感情的な快適さ
9. **正誤** - 正しいか間違っているか

**例として挙げられている具体的な判断:**
- 「時間にルーズ」への寛容さ
- 「タメ口」への許容度
- 各模倣人格が**独自の閾値**で判断

## 重要な発見：MBTIやビッグファイブとの違い

### MBTIやビッグファイブの位置づけ
- **性格診断**として使用される
- ユーザと模倣人格の**性格類似度**を測定するために使用
- 模倣人格の精度を判断するための指標

### 価値観波形の位置づけ
- **価値観評価**として使用される
- 具体的な**言動項目**に対する評価
- 複数の模倣人格による**多角的評価**
- 「徳」「地雷」という**行動に対する評価**

### 根本的な違い
| 項目 | MBTI/ビッグファイブ | 価値観波形 |
|------|---------------------|------------|
| 評価対象 | 性格特性 | 具体的な言動 |
| 評価方法 | 質問への回答 | 言動の監視・評価 |
| 評価者 | 本人（自己申告） | 複数の模倣人格（他者視点） |
| 結果 | 性格タイプ/スコア | 徳/地雷の累積波形 |
| 更新頻度 | 診断時のみ | 言動ごとに動的更新 |

## ユーザーの指摘との関連

ユーザーの例：
> 「大地震があったときにボランティアにいきますか？」
> 「言ってる人いたらどう思いますか？」

これは特許の「言動項目に対する評価」に該当する：
1. **具体的なシナリオ**（大地震時のボランティア）を提示
2. ユーザーの**回答や反応**を収集
3. 複数の模倣人格が**それぞれの価値観で評価**
4. 「徳」「地雷」「問題なし」として**累積**

### 動的評価の必要性
- 1,2,3,4,5の静的スコアではなく
- 具体的な状況に対する反応を**動的に評価**
- 評価は**累積**されて波形を形成

## 実装への示唆

### 現在の実装の問題点
- 性格診断結果（MBTI/ビッグファイブ）から波形を生成している
- これは特許の意図とは異なる

### 特許に基づく正しい実装
1. **価値観シナリオの提示**
   - 具体的な状況（大地震、ビジネス判断など）を提示
   - ユーザーの反応を収集

2. **複数の模倣人格による評価**
   - 各模倣人格が独自の価値観で評価
   - 「徳」「地雷」「問題なし」を判定

3. **評価の累積**
   - 対話ごとに評価を累積
   - 波形として可視化

4. **9つの判断基準の活用**
   - 善悪、好き嫌い、損得など
   - 各基準での閾値を設定
